# Implementation Plan: Search Screen with Library Statistics & Discovery

**Branch**: `008-search-screen-discovery` | **Date**: 2026-08-16 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/008-search-screen-discovery/spec.md`

## Summary

Implement the dedicated Search Screen featuring:
1. Top Neobrutalist search bar with live filtering, clear button, and "Cancel" back navigation.
2. "YOUR LIBRARY" summary card displaying live counts for Collections, Links, Pinned items, and unique Tags.
3. "RECENTLY SAVED" section containing a horizontal carousel (`LazyRow`) of recent bookmark cards with preview thumbnails, collection badges, and source platform indicators.
4. Real-time instant search filtering across titles, URLs, collection names, and tags, dynamically hiding Discovery items to show search results.
5. Navigation integration (`NavRoutes.SEARCH`), Neobrutalism dual-theme support (Light & Catppuccin Mocha Dark), and bilingual string localization (`en` and `pt-BR`).

## Technical Context

**Language/Version**: Kotlin 2.2.10 (JVM Target 17)

**Primary Dependencies**: Jetpack Compose (BOM), Material 3, Hilt 2.60.1, Room 2.8.4, Coil Compose 2.7.0, Kotlin Coroutines & Flow

**Storage**: Local Room Database (`AppDatabase`, `BookmarkDao`, `CollectionDao`) via `BookmarkRepository` and `CollectionRepository`

**Testing**: JUnit 4, MockK 1.14.11, kotlinx-coroutines-test 1.11.0 (`./gradlew test`)

**Target Platform**: Android (minSdk 26, targetSdk 35)

**Project Type**: Mobile Application (Native Android)

**Performance Goals**: Search query evaluation <50ms, 60fps LazyList/LazyRow scrolling, instant reactive state transitions

**Constraints**: Offline-first (local Room cache queries), Strict Neobrutalism Design System adherence (`ui/theme/Color.kt`, hard shadows)

**Scale/Scope**: 1 dedicated screen (`SearchScreen`), 1 ViewModel (`SearchViewModel`), 4 sub-composables, string localization in 2 locales.
