# Implementation Plan: Create New Collection Modal

**Branch**: `009-create-collection` | **Date**: 2026-08-16 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/009-create-collection/spec.md`

## Summary

Implement the "Add new collection" bottom sheet modal:
1. **Neobrutalism Bottom Sheet Container**: Drag handle, localized title, and 'X' close button.
2. **Name Input Field**: Single-line text field with placeholder, 40-character max limit, dynamic `current/40` counter, and blank validation.
3. **16-Color Neobrutalism Palette Grid**: Visual swatches with checkmark indicator on selection.
4. **43-Icon Curated Grid**: 8-column icon selector where the active icon is filled with the currently selected color.
5. **Shared Registries**: Centralized `CollectionIconRegistry` and `CollectionPalette` to ensure icons and colors are rendered consistently across the entire app (`NeobrutalistFolderCard`, `CollectionHeader`, etc.).
6. **Repository & UI Integration**: Update `CollectionRepository.createCollection` to accept `iconKey`, wire `HomeScreenTopBar` and `SaveBookmarkBottomSheet` triggers, add bilingual string localization (`en` and `pt-BR`), and provide unit tests in `CreateCollectionViewModelTest`.

## Technical Context

**Language/Version**: Kotlin 2.2.10 (JVM Target 17)

**Primary Dependencies**: Jetpack Compose (BOM), Material 3, Material Icons Extended, Hilt 2.60.1, Room 2.8.4, Kotlin Coroutines & Flow

**Storage**: Local Room Database (`AppDatabase`, `CollectionDao`, `CollectionEntity`) via `CollectionRepository`

**Testing**: JUnit 4, MockK 1.14.11, kotlinx-coroutines-test 1.11.0 (`./gradlew test`)

**Target Platform**: Android (minSdk 26, targetSdk 35)

**Project Type**: Mobile Application (Native Android)

**Performance Goals**: State updates <50ms, 60fps smooth modal presentation and scrolling, instant reactive persistence

**Constraints**: Offline-first, Neobrutalism Design System tokens (`ui/theme/Color.kt`, 2.5dp borders, hard offset shadows)

**Scale/Scope**: 1 bottom sheet modal, 1 ViewModel, 2 picker sub-composables, 2 registries/helpers, string localization in 2 locales.
